## Kết quả nổi bật

- Tự động hóa provisioning hạ tầng AWS bằng Terraform modules; thời gian triển khai còn **dưới 15 phút**.
- Chuẩn hóa triển khai frontend, backend và MySQL trên EKS bằng Helm và GitOps với Argo CD.
- Kết nối kiểm thử, build, push image lên ECR và cập nhật Helm values trong GitHub Actions.
- Rút ngắn thời gian release xuống **xấp xỉ 5 phút**.
- Tích hợp kiểm tra bảo mật và monitoring để tăng khả năng phát hiện sớm vấn đề vận hành.
